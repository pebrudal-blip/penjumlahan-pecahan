```html Game Penjumlahan Pecahan

🍕 Penjumlahan Pecahan

Pelajari penjumlahan pecahan melalui potongan-potongan lingkaran.

⭐ Skor: 0
🎯 Soal: 1
✅ Benar: 0
Hitung penjumlahan berikut:
🔎 Tahapan Permainan
1. Pecahan
2. Samakan
3. Gabungkan
4. Hitung
5. Jawab
Pecahan Pertama
+
Pecahan Kedua
🧮 Proses Penjumlahan
✏️ Sekarang tentukan hasil penjumlahannya!
/
📖 Cara Bermain
  1. Perhatikan dua pecahan pada soal.
  2. Amati bagian yang diarsir pada masing-masing lingkaran.
  3. Klik Samakan Potongan untuk membuat jumlah bagian kedua lingkaran sama.
  4. Klik Gabungkan untuk menggabungkan kedua pecahan.
  5. Klik Hitung Bagian untuk menghitung banyak bagian yang diarsir.
  6. Masukkan pembilang dan penyebut hasilnya.
🧠 Konsep Matematika

Jika penyebut berbeda, pecahan harus diubah menjadi pecahan senilai terlebih dahulu.

Contoh:

1/2 + 1/4

Penyebut 2 dan 4 disamakan menjadi 4:

2/4 + 1/4

Kemudian bagian yang diarsir digabung:

2/4 + 1/4 = 3/4

```
