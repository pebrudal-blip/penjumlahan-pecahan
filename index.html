🍕 Penjumlahan Pecahan

Lihat bagaimana bagian-bagian pecahan bergabung menjadi satu kesatuan.

⭐ Skor: 0
🎯 Soal: 1
✅ Benar: 0
Hitung penjumlahan berikut:
🔎 Tahapan Permainan
1. Pecahan
2. Samakan
3. Gabungkan
4. Hitung
5. Jawab
🧮 Proses Penjumlahan
✏️ Tentukan hasil penjumlahannya!
/
📖 Cara Bermain
  1. Perhatikan kedua pecahan.
  2. Klik Samakan Potongan.
  3. Klik Gabungkan dan perhatikan perpindahan bagian secara perlahan.
  4. Jika sebuah lingkaran sudah penuh, lingkaran baru akan muncul otomatis.
  5. Klik Hitung Bagian.
  6. Masukkan hasil penjumlahan.
🧠 Contoh

2/3 + 2/3 = 4/3

Karena satu lingkaran hanya dapat memuat 3/3, maka proses visualnya adalah:

3/3 + 1/3

= 4/3
